# AirString

A browser-based air-string instrument: create strings with two hands and pluck them with fingertip motion. Hand tracking and synthesis run locally in the browser; camera frames are not uploaded.

## Run

Start the included HTTPS server and open its HTTPS address in a modern browser. Camera access requires a secure context. The bundled MediaPipe runtime and hand model allow offline operation after the repository is cloned.
